# Fiverr Portfolio Details

## Title
E-Commerce Web Scraping & Analytics Dashboard

## Short Description
Built a complete data automation solution to extract public e-commerce product data, clean and structure the dataset, export CSV/Excel files, store the data in SQLite and visualize the results in an interactive dashboard.

## What Was Delivered
- Automated scraping pipeline
- Clean CSV and Excel datasets
- SQLite database
- Interactive dashboard
- Price analysis
- Availability analysis
- Rating analysis
- Downloadable processed data

## Skills
Python, Web Scraping, BeautifulSoup, Requests, Pandas, Streamlit, Plotly, SQLite, Excel, CSV, Data Cleaning, Data Automation

## Business Value
This solution helps businesses replace manual data collection with an automated workflow for product research, price monitoring, catalog extraction and reporting.
