## 📝 Gig Description (Copy & Paste)

Are you looking to automate your e-commerce data collection, monitor competitor pricing, or analyze catalog inventory without manual copy-pasting? Look no further! 

I build **complete, robust, and professional web scraping systems and data analytics dashboards** tailored to your business needs. 

This portfolio project is a live demonstration of an **end-to-end Data Engineering and BI Dashboard** solution. It extracts public product data from an e-commerce platform, sanitizes and organizes it, saves it in a robust SQL database, and builds an interactive client dashboard.

### 🌟 Key Features of this Service:
1. **Polite, Multi-Page Web Scraping:** High-speed extraction using `requests` and `BeautifulSoup4`. Features integrated request delays, retries, and browser agent rotation to ensure stable, polite scraping.
2. **Robust Data Extraction:** Captures critical attributes including **Title, Price, Star Ratings, Real-Time Availability, SKUs (UPC), and Product Categories**.
3. **Advanced ETL & Data Transformation:** Cleans dirty HTML text, strips currency symbols, maps textual ratings to numbers, identifies stock counts, removes duplicates, and flags pricing tiers (Budget/Moderate/Premium).
4. **Structured Storage & Databases:** Saves organized data to standard CSV, professional Excel spreadsheets (`.xlsx`), and loads records into a structured SQLite database.
5. **Modern Streamlit Dashboard:** A responsive BI web app with:
   - Key Performance Indicators (KPIs) showing essential metrics.
   - Interactive data visualizations (Plotly histograms, bar charts, and category summaries).
   - Global search & multi-layer filtering (price range, ratings, categories).
   - Instant data exports (CSV & Excel) for the filtered dataset.
   - An **interactive control panel** to run the scraper directly from the web browser!

### 🛠️ Tech Stack & Technologies:
- **Core:** Python 3.8+
- **Scraping:** Requests, BeautifulSoup4
- **ETL/Analytics:** Pandas, NumPy
- **Database:** SQLite3
- **Visualization:** Streamlit, Plotly
- **File Export:** Openpyxl
